# 🐍 Snake Game - Python

A classic Snake Game implemented in Python using the `pygame` library.

## ✨ Features
- 🎮 Arrow Key Controls
- 🍎 Food Collection & Snake Growth
- 📈 Live Score Display
- 💥 Collision Detection (Wall & Self)
- 🔄 Restart (`R`) & Quit (`Q`) options

## 🛠 Tech Stack
- Python 3.x
- Pygame 2.0+
