# Snake Game 🐍

A simple Snake game made with Python and Pygame.

## About the Game
This is the classic Snake game. You control a snake to eat food and grow longer. The game ends if you hit the wall or your own tail.

## Features
- Use arrow keys to move the snake
- Eat red food to grow and increase your score
- See your current score on the screen
- Game over screen with your final score
- Press `R` to restart the game
- Press `Q` to quit the game

## How to Play
1. Use the **Arrow Keys** (↑ ↓ ← →) to change the snake's direction.
2. Eat the red square to gain 1 point and make the snake longer.
3. Do not hit the wall or your own body.

## Tech Stack
- Python 3.x
- Pygame 2.0+
